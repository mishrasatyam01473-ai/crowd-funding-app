# Frontend Client

Client-side Single Page Application (SPA) for the crowdfunding platform, built with React and Vite.

## Available Scripts

In this directory, you can run:

- `npm run dev`: Starts the local development server (default port 5173).
- `npm run build`: Compiles and bundles production-ready assets into the `dist/` directory.
- `npm run preview`: Locally previews the built production bundle.

## Environment Variables

- `VITE_API_URL`: Points to your backend API base URL (defaults to `http://localhost:5000` when unset).
